# Счётчик расчётов «Цель миллион»

Показывает на лендинге только реальные события:

- в первом экране, рядом с лицензией и АСВ: «128 человек уже рассчитали свой план»;
- всплывающие подсказки «Кто-то рассчитал свой план · 7 500 ₽ в месяц · 3 минуты назад». Не чаще раза в 40–50 секунд, не больше трёх за визит и только по событиям за последние 30 минут.

«Рассчитал свой план» значит, что человек сам поменял параметры индивидуального плана или скачал PDF. Страница отправляет это один раз за сессию браузера.

## Важно: GitHub Pages сам по себе это не запустит

GitHub Pages отдаёт только статичные файлы, хранить и считать события ему негде. Поэтому нужен маленький серверный обработчик. Удобнее всего Cloudflare Worker с базой D1 на том же домене: оба есть в бесплатном тарифе.

Страница уже настроена. На своём домене по HTTPS она сама обращается к `/api/million/…`, а на `*.github.io` и локально счётчик выключен. Пока воркер не подключён, блок с числом и подсказки просто не появляются, страница работает как обычно.

## Подключение (один раз, около 10 минут)

1. Домен должен идти через Cloudflare: в DNS у записи сайта включено «оранжевое облако».
2. Установить Wrangler и войти: `npm i -g wrangler` → `wrangler login`.
3. В папке `counter/` создать базу: `wrangler d1 create million-counter`. Полученный `database_id` вписать в `wrangler.toml`.
4. Создать таблицы: `wrangler d1 execute million-counter --remote --file=schema.sql`.
5. В `wrangler.toml` заменить `million.example.ru` и `example.ru` на свой домен.
6. Задать соль для защиты от накрутки: `wrangler secret put SALT` (любая длинная строка).
7. Опубликовать: `wrangler deploy`.

Проверка: откройте `https://ВАШ-ДОМЕН/api/million/stats`, должен прийти ответ `{"total":0,"recent":[]}`. Затем поменяйте параметры в индивидуальном плане: через пару секунд число станет 1.

## Что хранится

Только сумма взноса, округлённая до 500 ₽, и время события. Адрес посетителя не сохраняется. Чтобы с одного устройства нельзя было накрутить, 10 минут хранится его солёный хеш, потом он удаляется.

## Почему не считаем посетителей как «оформивших»

Подпись «оформили план» к числу заходов на сайт сделала бы рекламу финансовой услуги недостоверной. Поэтому число и подсказки описывают только реальное действие.

## Другие варианты

`server.mjs` — тот же счётчик на Node.js для собственного сервера фонда. Адрес такого сервера можно задать на странице до основного скрипта: `<script>window.MILLION_COUNTER_URL = "https://…/million";</script>`.
