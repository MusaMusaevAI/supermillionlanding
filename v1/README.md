# «Цель — миллион» — демо-лендинг ПДС

Статическая страница без сборки и зависимостей. Открывается двойным кликом
по `index.html` либо публикуется через GitHub Pages.

- `index.html` — вся страница: разметка, стили, логика квиза и графика
- `calc.js` — движок расчёта ПДС
- `assets/` — изображения

Прототип для демонстрации. Тексты требуют юридической проверки,
формулы — подтверждения методологом. Кнопки оформления ведут на заглушки.
