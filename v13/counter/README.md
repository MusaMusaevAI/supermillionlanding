# Счётчик расчётов «Цель миллион»

Показывает на лендинге только реальные события:

- в первом экране, рядом с лицензией и АСВ: «128 человек уже рассчитали свой план»;
- всплывающие подсказки «Кто-то рассчитал свой план · 7 500 ₽ в месяц · 3 минуты назад» — не чаще раза в 40–50 секунд, не больше трёх за визит и только по событиям за последние 30 минут.

«Рассчитал свой план» значит, что человек сам поменял параметры в «Ваш план» или скачал PDF. Страница отправляет это один раз за сессию браузера.

## Почему на million.gazfond-pn.com сейчас ничего не появляется

Сайт отдаётся прямо с GitHub Pages (заголовок `server: GitHub.com`), запросы через Cloudflare не идут. Обработчика `/api/million` там нет, GitHub отвечает «404», и счётчику не из чего брать число. GitHub Pages умеет только отдавать файлы, хранить события ему негде. Поэтому нужен отдельный маленький обработчик — Cloudflare Worker с базой D1, оба бесплатные.

С v11 страница обращается к счётчику только по адресу, вписанному в `index.html` (`var COUNTER_URL = …`). Пока адрес пустой, никаких запросов и ошибок в консоли нет.

## Подключение: способ 1, через workers.dev (DNS не трогаем)

1. `npm i -g wrangler` → `wrangler login`.
2. В папке `counter/`: `wrangler d1 create million-counter`. Полученный `database_id` вписать в `wrangler.toml`.
3. Создать таблицы: `wrangler d1 execute million-counter --remote --file=schema.sql`.
4. Соль для защиты от накрутки: `wrangler secret put SALT` (любая длинная строка).
5. Опубликовать: `wrangler deploy`. Wrangler покажет адрес вида `https://million-counter.ИМЯ.workers.dev`.
6. В `index.html` вписать: `var COUNTER_URL = "https://million-counter.ИМЯ.workers.dev/api/million";` и загрузить на GitHub.

Проверка: откройте `https://million-counter.ИМЯ.workers.dev/api/million/stats` — должно прийти `{"total":0,"recent":[]}`. Затем поменяйте параметры в «Ваш план»: через пару секунд число на странице станет 1.

## Способ 2: маршрут на своём домене

Если запись `million` в DNS Cloudflare переключить на «оранжевое облако» (SSL/TLS в режиме Full), в `wrangler.toml` можно включить строку `routes` и вписать `var COUNTER_URL = "/api/million";`. Тогда счётчик работает по адресу самого сайта.

## Что увидит посетитель сразу после запуска

Пока событий 0, блок с числом скрыт. Всплывающие подсказки появляются, только если кто-то рассчитал план за последние 30 минут. На свежем счётчике их не будет, пока не пойдут реальные расчёты.

## Что хранится

Только сумма взноса, округлённая до 500 ₽, и время события. Адрес посетителя не сохраняется: 10 минут хранится только его солёный хеш (чтобы с одного устройства нельзя было накрутить), потом он удаляется.

## Почему не считаем посетителей как «оформивших»

Число и подсказки описывают реальное действие. Подпись «оформили план» к числу заходов на сайт сделала бы рекламу финансовой услуги недостоверной.
