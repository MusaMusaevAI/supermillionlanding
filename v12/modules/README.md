# Калькуляторы «Цель миллион» отдельными модулями

Два независимых калькулятора с лендинга v12. Каждая папка — готовая страница без внешних зависимостей: её можно выложить на любой сервер и встроить на сайт через `iframe`. Расчёт, тексты и дизайн те же, что на лендинге.

| Папка | Что внутри |
|---|---|
| `hero-calc/` | Калькулятор первого экрана. Пример для женщины 35 лет с доходом 100 тыс. ₽: ползунок, быстрый выбор и своя сумма взноса. Показывает срок до миллиона и насколько это раньше, чем в копилке. Диаграмма «ваши взносы + что добавит ПДС» рядом с полосой копилки без процентов. Кнопка Госуслуг, напоминание в календарь, ссылка на «Ваш план». |
| `plan-calc/` | «Ваш план». Режимы «знаю взнос» / «знаю срок»; возраст, пол, доход, цель, стартовый взнос, вычет. Когда доступны выплаты, график, из чего сложится сумма. Кнопка Госуслуг, план в PDF, напоминание. Ниже условия расчёта и правовая информация. |

## Встраивание

```html
<iframe src="https://ВАШ-АДРЕС/hero-calc/" style="width:100%;max-width:540px;height:1150px;border:0" title="Калькулятор ПДС"></iframe>
<iframe src="https://ВАШ-АДРЕС/plan-calc/" style="width:100%;height:1700px;border:0" title="Ваш план ПДС"></iframe>
```

- Тема по умолчанию как в системе посетителя. Задать явно: `?theme=light` или `?theme=dark`.
- На телефоне «Ваш план» работает как на лендинге: сначала параметры, затем «Показать результат».
- PDF на телефоне открывает системное «Поделиться», на компьютере скачивается A4 в альбомной ориентации. Для этого в `plan-calc/` нужна папка `media/pdf`.

## Что настроить перед публикацией

1. `hero-calc/index.html`: `PLAN_URL` — куда ведёт «Рассчитать свой план». Сейчас `https://million.gazfond-pn.com/v12/#calc`, можно указать адрес модуля `plan-calc`.
2. `plan-calc/index.html`: `PAGE_URL` — адрес, который попадает в напоминание в календаре. Сейчас `https://million.gazfond-pn.com/v12/`.
3. В обоих файлах `METRIKA_ID` — номер счётчика Яндекс Метрики; код счётчика вставить в `<head>`. Цели те же, что на лендинге, плюс `widget_hero_view`.
4. `plan-calc/index.html`: `COUNTER_URL` — адрес счётчика реальных расчётов (см. `counter/README.md` лендинга). Пока поле пустое, ничего не отправляется.

Ссылки на Госуслуги размечены `utm_medium=widget_hero` и `utm_medium=widget_plan`, чтобы заявки из модулей отличались от заявок с лендинга.
